# docs

lazypost is `an API client that lives in your terminal` — Posting-inspired, built with Go and Bubble
Tea. Requests are plain YAML files in a directory tree, so a collection is a folder you can
version-control, diff, and share.

## Guides

- [Quick start](/lazypost/docs/quickstart/) — First request in under a minute.
- [Installation](/lazypost/docs/installation/) — One command, a pinned version, or go build.
- [Keybindings](/lazypost/docs/keybindings/) — Every binding, grouped: global, sidebar, URL bar, editor, response.
- [Collections](/lazypost/docs/collections/) — Request YAML format, auth variants, folder structure.
- [Environments](/lazypost/docs/environments/) — {{variable}} interpolation and the environment manager.
- [Scripting](/lazypost/docs/scripting/) — Sandboxed Lua pre/post hooks with a session store.
- [Importers](/lazypost/docs/importers/) — Postman and Insomnia into a lazypost collection, one command.
- [Themes](/lazypost/docs/themes/) — Eight presets and custom YAML themes.
- [FAQ](/lazypost/docs/faq/) — Troubleshooting and behavior notes.
