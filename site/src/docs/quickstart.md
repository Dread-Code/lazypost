# quick start

Run `lazypost` in any directory — the current directory is initialized as a collection (with
`config/config.yaml`) when needed.

1. **run it anywhere** — `lazypost`
2. **create a request** — `n — then ctrl+l edits the URL, ctrl+t cycles the method`
3. **save and send** — `ctrl+s` saves, `ctrl+r` sends
4. **add environments** — drop YAML files in `environments/` and switch with `ctrl+e`

## $ run

```bash
# from the repo, with the sample collections
$ ./lazypost
$ ./lazypost -dir my-collection  # or point at your own collection directory
```
